Critical Essay: LLMs as a tool, not a Crutch

The statement "LLMs must be used as a tool not a crutch" means that AI should assist our learning rather than replace our core thinking. Using an LLM as a crutch involves letting it write all your code and solve logic problems for you, which prevents you from actually learning how to program.

Using an LLM as a tool means treating it like an assistant or tutor. As noted in AI literacy research, models are great for explaining tricky error messages, reviewing best practices, or clarifying concepts after you have tried solving the problem yourself (Mollick & Mollick, 2023). In my studies, I write my core logic from scratch and only use AI to understand syntax errors.
